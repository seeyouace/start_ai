# Agent Eval & Harness 设计文档
## 目标
传统接口测试无法衡量Agent输出质量；Harness用于自动化批量评测Agent任务，做迭代回归，量化Agent效果。

## 评测维度
1. 任务成功率：是否完成用户目标任务
2. 工具调用正确性：是否选对工具、参数是否正确
3. 回答相关性：回答和用户问题是否匹配
4. 幻觉率：是否编造不存在事实
5. 资源指标：总token消耗、LLM调用轮次、执行耗时

## 评测方案
1. 人工标注测试集：准备一批真实业务测试case，包含输入+预期结果
2. LLM-as-judge：使用大模型自动打分，输出结构化评分
3. 批量执行：Harness读取数据集，自动调用Agent执行任务，采集输出与指标
4. 生成评测报告：汇总所有case指标，版本对比，看Agent迭代效果变好/变差

## Harness模块
- 用例管理：保存评测数据集，版本管理测试用例
- 任务调度：批量执行Agent任务，限流防止打爆模型
- 结果存储：保存Agent输出、LLM judge打分、token指标
- 报告输出：Markdown / 可视化评测汇总

## 评测流程
1. 导入测试用例
2. Harness批量发起Agent任务
3. 记录执行轨迹、token消耗、Agent输出
4. LLM Judge评估输出质量，打分
5. 生成评测报告，对比不同Agent版本效果
